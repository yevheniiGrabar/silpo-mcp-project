# AGENTS.md — інваріанти проєкту (не порушувати)

Читається кожним агентом перед роботою. Це «правила гри», які важливіші за будь-яку окрему задачу.

## Продукт
- Застосунок «Розумний кошик»: меню на тиждень + кошик Сільпо, **два режими** — `economy` (жорсткий бюджет, promotion-first) та `quality` (мʼякий бюджет +10–30%, preference-first).
- Killer-фіча: рекомендації з історії покупок («патерн пʼятниці»).
- Демо доводить економію двома корзинами + лічильник.

## Архітектура
- **Flutter → наш Laravel BFF → mcp.silpo.ua.** Flutter НІКОЛИ не ходить у MCP і не тримає токен Сільпо.
- **LLM** (Claude) планує меню й пояснює заміни. **Матчинг SKU, ціни й бюджет — детермінований PHP-код**, не LLM.
- Токени Сільпо — server-side, encrypted.
- Laravel: суворо Controller → Service → Repository. Запити до БД — тільки в репозиторіях.

## MCP (див. docs/06 — ПЕРЕВІРЕНО наживо)
- Інструменти з префіксом `silpo_`. Транспорт: JSON-RPC, initialize→notifications/initialized→tools/call, protocol 2025-06-18.
- **ФУТГАН:** products/promotions вимагають branchId+deliveryType+timeslotStart+timeslotEnd; з НЕдоступним слотом → 0 результатів. Порядок: list_branches → deliveryType → get_time_slots(available:true) → потім пошук.
- **Матчинг:** «перший/найдешевший» промахується ~30–40% (корм/приправи/готові страви). Ре-ранкінг по КАТЕГОРІЇ + top-3 + confidence обовʼязковий.
- **Кошик:** не створюється через MCP — використовуй активний кошик гостя (get_my_shopping_cart → by_id). Checkout = поля `checkoutWebLink` + `checkoutMobileLink`.

## Правила збірки
- Гілки `claude/<phase>`, PR, ніколи не пуш у `main` напряму.
- Verify-then-push: acceptance-команди мають бути зелені (див. docs/07).
- Не міняти ключові рішення без згоди людини.

## Хакатон (жорсткі умови)
- Конект саме до `https://mcp.silpo.ua/mcp`, ≥1 tool у робочому сценарії, видиме demo з JSON-RPC логом, токени серверно, чіткий Гість+проблема+цінність. MCP — у центрі, не «AI лише генерує текст».
