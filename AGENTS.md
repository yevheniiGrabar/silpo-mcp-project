# AGENTS.md — інваріанти проєкту «Останній Шанс» (не порушувати)

Читається кожним агентом перед роботою.

## Продукт (актуальний — ПІВОТ)
«Останній Шанс» (Last-Chance Engine): агент розбирає бонуси/купони гостя за термінами згорання і збирає персональну пропозицію, де стимул-що-згорає оплачує супер-ціну на ЙОГО ЗВИЧНИЙ товар. Killer: економія гостя = скорочення 2 збитків Сільпо (breakage + списання). Канали: Telegram-бот + B2B-дашборд.
⚠️ Meal-planner (docs 01-05,08) — LEGACY, НЕ будувати. Джерело істини: `00-OVERVIEW`, `CONCEPT-LAST-CHANCE`, `PITCH-LAST-CHANCE`, `LC-BUILD`, `LC-PHASES`, `06-MCP-VERIFIED`.

## Позиціонування (жорстко)
- Особиста вигода «твій бонус + супер-ціна на твій звичний товар», НЕ «врятуй списання».
- Пушити тільки товари з привичної корзини (get_my_offline_orders).
- UX = один тап, без екранів умов.

## Архітектура
- Гість (Telegram) / менеджер (web-дашборд) → Laravel BFF → mcp.silpo.ua. Токени Silpo server-side (encrypted).
- **Матчинг/ціни/стимули — детермінований PHP-код**, LLM лише розуміє намір і формулює пояснення (tone-guardrail: дружньо, про вигоду, ніколи не тиск/сором).
- Laravel: Controller → Service → Repository. БД — тільки в репозиторіях.

## MCP (див. 06 — перевірено наживо)
- Tools з префіксом `silpo_`. Порядок: контекст (branch→deliveryType→**available slot**) → потім products/promotions. Недоступний слот → 0 результатів.
- Купон має `endDate` (перший дедлайн — реальний). Уцінки: get_products(mustHavePromotion,inStock) + рахунок discount% (near-expiry proxy). get_my_certificates може дати 500 → фолбек. Кошик не створюється через MCP (лише активний + checkoutWebLink).

## Правила збірки
- Гілки `claude/<phase>`, PR, ніколи не пуш у main напряму.
- Verify-then-push: acceptance зелені (php artisan test, pint --test, php -l).
- Safe-default: нічого не купується без явного тапу гостя.
- Не міняти ключові рішення (Last-Chance концепт, детермінований матчинг, токени серверно, позиціонування) без згоди людини.

## Хакатон
Конект саме до mcp.silpo.ua, ≥1 tool у робочому сценарії (у нас ~13), видиме demo з JSON-RPC логом, токени серверно, чіткий Гість+проблема+цінність. MCP у центрі.
