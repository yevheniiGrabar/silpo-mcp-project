# «Розумний кошик» — meal-planner на Silpo MCP (+ калорії, заміна страв, підписка)

Мобільний застосунок: планує **меню на тиждень під бюджет**, збирає кошик Сільпо, показує **калорійність/БЖУ**, дозволяє **замінити страву** і монетизується через **freemium-підписку**. Усе через офіційний **Silpo MCP**.

## Для AI-агента-виконавця — читати по порядку
1. **`AGENTS.md`** — інваріанти.
2. **`docs/00-OVERVIEW.md`** — продукт, архітектура, монетизація, джерело калорій.
3. **`docs/01-BACKEND.md`** — Laravel: БД, MCP-клієнт, OAuth, сервіси, API.
4. **`docs/02-AI-AGENT.md`** — агент планування (laravel/ai), промпти, детермінований оптимізатор.
5. **`docs/03-FLUTTER.md`** — застосунок: екрани, стан, анімації.
6. **`docs/04-DESIGN-SYSTEM.md`** — кольори, типографіка, компоненти.
7. **`docs/06-MCP-VERIFIED.md`** — ⚠️ ПЕРЕВІРЕНІ факти MCP (футган слота, ре-ранкінг, кошик, checkout). Читати ПЕРЕД інтеграцією.
8. **`docs/07-BUILD-ORCHESTRATION.md`** — фази, залежності, acceptance, verify-then-push.
9. **`docs/09-EXTRAS.md`** — калорійність, заміна страв, freemium-підписка (нові фічі).

## ⚡ РЕКОМЕНДОВАНО для хакатону — легкий агент
- **`docs/AGENT-LITE-PLAN.md`** — тонкий розмовний агент (Claude Agent SDK + Silpo MCP + Telegram + планувальник тригерів). Менше коду, швидше demo. Важкий Laravel+Flutter (docs 00-09) = product/vision.

## Мультиагентна збірка
- **`KICKOFF.md`** — старт (коннектори + готовий промпт для Cowork/Dispatch).
- **`ORCHESTRATOR.md`** — промпт головного агента: воркери → verify → PR у `claude/*`.
- **`BUILD-STATE.json`** — стан фаз (створює оркестратор).

## Головні інваріанти
- Flutter → наш Laravel → Silpo MCP. Токени Сільпо server-side.
- Матчинг/ціни — детермінований код; LLM — меню, калорії, пояснення.
- Джерело калорій СВОЄ (LLM/нутрієнт-база), `PriceSource`-абстракція для відвʼязки.
- Оплату товарів у застосунку не беремо (checkout-лінк). Підписка — окремий білінг.
- MCP у центрі; демо з видимим JSON-RPC логом.
