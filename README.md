# «Останній Шанс» (Last-Chance Engine) — Silpo AI Factory

AI-агент, який розбирає бонуси/купони гостя за термінами згорання і збирає персональну пропозицію, де **стимул-що-згорає оплачує супер-ціну на його ЗВИЧНИЙ товар**. Економія гостя = скорочення двох збитків Сільпо (breakage непогашених бонусів + списання near-expiry). Канали: **Telegram-бот** + **B2B-дашборд**. Усе через офіційний **Silpo MCP**.

## Для AI-агента-виконавця — читати по порядку
1. **`AGENTS.md`** — інваріанти (не порушувати).
2. **`docs/00-OVERVIEW.md`** — продукт, архітектура, killer, позиціонування.
3. **`docs/CONCEPT-LAST-CHANCE.md`** — концепція + ринкова валідація + докрутки.
4. **`docs/06-MCP-VERIFIED.md`** — ⚠️ ПЕРЕВІРЕНІ наживо факти MCP (футган слота, купон endDate, уцінки, кошик, checkout-лінки). Читати ПЕРЕД інтеграцією.
5. **`docs/LC-BUILD.md`** — детальне ТЗ що будувати (backend, ядро-матчинг, TG-бот, дашборд, БД, API).
6. **`docs/LC-PHASES.md`** — фази, залежності, acceptance, verify-then-push.
7. **`docs/PITCH-LAST-CHANCE.md`** — текст для подачі (6 карток) + demo-план.

## Мультиагентна збірка
- **`KICKOFF.md`** — з чого стартувати (коннектори + готовий промпт для Cowork/Dispatch).
- **`ORCHESTRATOR.md`** — промпт головного агента: воркери → verify → PR у `claude/*`.
- **`BUILD-STATE.json`** — стан фаз.

## ⚠️ LEGACY (НЕ будувати)
`docs/01-05`, `docs/07` описують попередній meal-planner (концепт ЗМІНЕНО). Ігнорувати для збірки; лишені лише як історія.

## Головні інваріанти
- Telegram/дашборд → наш Laravel → Silpo MCP. Токени Сільпо server-side.
- Матчинг/ціни — детермінований код; LLM лише намір+пояснення (tone-guardrail).
- Особиста вигода, НЕ «врятуй списання». Тільки звичні товари. Один тап.
- MCP у центрі; демо з видимим JSON-RPC логом.
