# Розумний кошик — проєкт для хакатону Сільпо AI Factory

Мобільний застосунок (Flutter) + бекенд (Laravel), який планує меню на тиждень
**навколо акцій Сільпо**, укладає кошик у бюджет з максимальною користю, вчиться на
історії покупок і збирає готовий кошик через офіційний **Silpo MCP** (`mcp.silpo.ua/mcp`).

## Для AI-агента-виконавця

Читай `docs/` по порядку — це повне ТЗ:

1. **`docs/00-OVERVIEW.md`** — продукт, архітектура, стек, ключові рішення, критерії журі.
2. **`docs/01-BACKEND.md`** — Laravel BFF: встановлення, БД/міграції, MCP-клієнт, OAuth, сервіси, репозиторії, контролери, API.
3. **`docs/02-AI-AGENT.md`** — які агенти, як під'єднати Claude+MCP через `laravel/ai`, системні промпти, структурований вихід, детермінований оптимізатор.
4. **`docs/03-FLUTTER.md`** — застосунок: пакети, архітектура, екрани, стан, анімації.
5. **`docs/04-DESIGN-SYSTEM.md`** — кольори, типографіка, компоненти, рух (Apple HIG «Fresh Market Minimal»).
6. **`docs/05-TIMELINE-CHECKLIST.md`** — 2-тижневий план, сценарій демо, чек-ліст відповідності хакатону.
7. **`docs/06-MCP-VERIFIED.md`** — ⚠️ ПЕРЕВІРЕНІ наживо факти MCP (реальні відповіді, футгани, обов'язковий порядок викликів). Читати ПЕРЕД кодуванням інтеграції.
8. **`docs/07-BUILD-ORCHESTRATION.md`** — карта фаз (backend+mobile), залежності, acceptance-команди, verify-then-push.

## Мультиагентна збірка
- **`AGENTS.md`** — інваріанти проєкту (читає кожен агент).
- **`ORCHESTRATOR.md`** — промпт головного агента-оркестратора: керує воркерами, перевіряє acceptance, пушить у `claude/*` + PR. Встав як інструкцію в Cowork/Dispatch, Agent Teams lead або routine.
- **`BUILD-STATE.json`** — стан фаз (створює оркестратор).

## Головні інваріанти (не порушувати)
- Flutter → наш Laravel → Silpo MCP. Токени Сільпо **тільки серверно**.
- LLM планує меню й пояснює заміни; **матчинг/ціни/бюджет — детермінований код**.
- Promotion-first; «максимум користі за бюджет», не «найдешевше».
- MCP у центрі кожного ключового екрана (інакше дискваліфікація).
- Демо: видимий JSON-RPC лог викликів mcp.silpo.ua.
