# 00 · Overview — «Розумний кошик» (meal-planner на Silpo MCP)

> ПРОДУКТ ПРОЄКТУ (актуальний). Це ТВІЙ застосунок: планувальник меню під бюджет на Silpo MCP + **калорійність страв**, **заміна страв** і **підписка (freemium)**. Читати: `00` → `01` (backend) → `02` (agent) → `03` (flutter) → `04` (design) → `06` (MCP-verified) → `07` (phases) → `09` (калорії/заміна/підписка).

## 1. Продукт
Мобільний застосунок, який планує **меню на тиждень під бюджет гостя** й збирає готовий кошик Сільпо. Гість обирає філію, бюджет, уподобання, алергії, техніку та режим (`economy`/`quality`) — AI будує меню навколо акцій Сільпо, підбирає реальні товари, укладається в бюджет і показує економію. **Нове:** для кожної страви — **калорійність + БЖУ**; будь-яку страву можна **замінити** («не подобається → заміни»); монетизація через **freemium-підписку**.

## 2. Ключові рішення
| Рішення | Чому |
|---|---|
| Два режими economy/quality | обслуговуємо ціновий і преміальний сегмент; знімає страх канібалізації маржі |
| Promotion-first (economy) | меню від акцій; рухає акційний/private-label сток |
| Детермінований матчинг/оптимізатор у бекенді, НЕ LLM | стабільно, без галюцинацій цін |
| Історія покупок («патерн пʼятниці») | персональні рекомендації |
| **Калорійність/БЖУ на страву** | цінність гостю; преміум-фіча підписки |
| **Заміна страви (live re-plan)** | контроль гостя; killer-момент demo |
| **Freemium-підписка** | монетизація (free=1 меню/тижд, paid=безліміт+калорії+заміна+профілі) |
| Токени Сільпо серверно | вимога/безпека |

## 3. Архітектура
```
Flutter app ─► Laravel BFF (агент + детермінований матчинг + токени + біллінг) ─► mcp.silpo.ua
                                     └► платіжний провайдер (підписка)
```
- Flutter НІКОЛИ не ходить у MCP і не тримає токен Сільпо. Тільки → наш Laravel.
- Laravel: OAuth Сільпо, матчинг/оптимізатор (код), калорії, заміна, **підписка/біллінг + gating платних фіч**.
- LLM (Claude): планування меню, оцінка калорій, пояснення замін. Ціни/матчинг — код.

## 4. Стек
Backend: PHP 8.3+, Laravel 12, MySQL, Redis, `laravel/ai`+`laravel/mcp` (або raw JSON-RPC фолбек), Anthropic. Біллінг: **Creem / Stripe / Paddle** (веб-підписка) або укр-еквайринг (Fondy/WayForPay/LiqPay); у сторах — їх IAP.
Frontend: Flutter (Riverpod, dio, freezed, go_router, flutter_animate) + екрани paywall/підписки.

## 5. Джерело калорій (важливо)
Silpo MCP структурований склад/калорії НЕ гарантує (`get_product_details` бува маркетинговий). Тому калорії/БЖУ:
- базово — **LLM-оцінка** по інгредієнтах і порціях (Claude);
- точніше (стретч) — власна нутрієнт-мапа/API (USDA/Nutritionix/Edamam).
Тримати джерело калорій СВОЇМ, не покладатись на MCP.

## 6. Монетизація (freemium)
- **Free:** 1 меню/тиждень, базовий список.
- **Paid (~4-8$/міс):** безліміт меню, **калорії/БЖУ**, **заміна страв**, профілі сімʼї/алергій, історія, експорт.
- Gating платних фіч у Laravel (middleware/policy per subscription).
- ⚠️ Чесно: монетизація ПОВЕРХ Silpo MCP комерційно потребує згоди Сільпо (MCP — їхній). Для хакатону/MVP ок; для продажів — узгодити з Сільпо або відвʼязати джерело даних пізніше (див. `09`).

## 7. MCP (перевірено — `06`)
Tools `silpo_`; порядок: контекст (branch→deliveryType→**available slot**) → products/promotions. Кошик не створюється через MCP (активний + checkoutWebLink). Оплату товарів у застосунку НЕ беремо — checkout-лінк Сільпо (підписка — окремий білінг, не плутати).
