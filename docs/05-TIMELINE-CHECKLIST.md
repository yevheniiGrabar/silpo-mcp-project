## 2. Що показати на демо (сценарій, ~3 хв)
1. Логін через Сільпо (реальний OAuth).
2. Головна: картка «у п'ятницю ти брав… — додати?» + акції. (MCP: historial orders + promotions.)
3. Майстер за 2 екрани (швидко). Бюджет 1500 ₴, техніка, «ПП».
4. Генерація — **на екрані біжить JSON-RPC лог** викликів mcp.silpo.ua. ← обов'язкове «видиме демо».
5. Меню тижня.
6. Список: **дві корзини + економія 260 ₴** (анімований лічильник). Одна swap-заміна з поясненням.
7. Checkout → показати, що відкривається реальний кошик Сільпо. Оплату не тиснемо.
8. Слайд: валідація (середній % економії на N меню) + масштабування (лояльність, пуш акцій, інші ритейли коли відкриють MCP).

---

## 3. Валідація (закриває найслабший критерій)
- Прогнати 5–10 реальних людей / 3–5 меню.
- Зафіксувати: `naive_total` vs `optimized_total` → середній % економії.
- 1 слайд з цифрою + плани розвитку.

---

## 4. Масштабування (для питчу)
- Вбудувати як фічу в застосунок Сільпо + «Власний рахунок» (лояльність).
- Пуш-нагадування «зібрати кошик на тиждень» → retention.
- Мультиритейл — коли АТБ/Novus відкриють свої MCP (зараз лише Сільпо).

- [ ] Робоче demo з видимим викликом (запис + JSON-RPC лог).

- [ ] Чіткий Гість (сім'я, чутлива до ціни) + проблема (меню на тиждень у бюджет).
- [ ] Демонстрація цінності (економія + basket value).
- [ ] НЕ «AI лише генерує текст без MCP» — MCP у центрі кожного ключового екрана.

## 6. Ризики й запобіжники
| Ризик | Запобіжник |
|---|---|
| Галюцинації матчингу на демо | детермінований матчинг + прогріті сценарії |
| Латентність/429 | батчі до 30, backoff, кеш акцій, вузький демо-скоуп |
| OAuth-флоу зламався на сцені | тестовий акаунт з історією, перевірити напередодні |
| Бізнес-конфлікт «дешевше vs маржа» | «максимум користі за бюджет» + пріоритет акцій/private-label |
| Банальність | promotion-first хук + рекомендації з історії |
