# 10 · Монетизація, тарифи, платежі, інтеграції магазинів

> Фінальні плани для «Розумний кошик». Оплата — IAP (Apple/Google) + опційно веб-підписка. Ринок: не тільки Україна (US сильно, EU частково).

## 2. Ціни (регіонально; сторами через price-tiers)
| | Україна | США / ЄС |
|---|---|---|
| Pro / міс | ₴149 | $8.99–9.99 |
| Pro / рік (ГЕРОЙ, −~45%) | ₴990 | $49.99–59.99 |
| Family / міс | ₴249 | $12.99 |
| Lifetime (опц.) | — | $99 |
- **Річний = головний оффер** (більшість виручки). 7 днів безкоштовного тріалу Pro.
- US/EU дорожче (купівельна спроможність); у EU-країнах без «замовлення» — трохи дешевше / позиціювати як планувальник+КБЖУ.

## 3. Юніт-економіка (орієнтир)
COGS/Pro-юзер/міс ≈ **$0.3–1.3** (LLM меню/Зоряна/калорії/заміни — головне; дешева модель Gemini Flash/Haiku → нижня межа; STT device — безкоштовно; MCP free-tier; інфра ~$0.1).
При $9.99/міс нетто після 15% IAP ≈ $8.5 → **валова ~85%**. Річний $49.99 нетто ≈ $42 → ~$3.5/міс нетто, маржа ~75%. Здорово.

## 4. Модель платежів
- **Внутрішня цифрова підписка → ОБОВʼЯЗКОВО IAP** (Apple/Google). Свій Stripe усередині апа для цифрових фіч НЕ можна.
  - Apple: 30% 1-й рік → 15% з 2-го; **15% одразу** у Small Business Program (<$1M/рік).
  - Google Play: 15% на підписки.
- **Виняток (2025–2026):** США (Epic v. Apple) і ЄС (DMA) — дозволені зовнішні посилання на оплату (steering) → можна вести на веб-чекаут і не платити 30%.
- **Веб-підписка** (Creem/Stripe/Paddle, ~3%) — окремий шлях: оформлення на сайті, у апі логін (модель Netflix/Spotify). У US/EU легально вести туди посиланням.
- **Рекомендація:** старт — **IAP + RevenueCat** (крос-платформні підписки, entitlement `pro`, тріали, аналітика). Плюс веб-підписка як дешевший шлях; у US/EU steering на веб. Руками платіж у апі не робити.

## 5. Налаштування IAP (у власних дев-акаунтах ПЕРЕД публікацією)
**Apple — App Store Connect:**
1. Підписати Paid Apps Agreement + заповнити Banking/Tax (Agreements, Tax, and Banking).
2. App → Subscriptions → створити Subscription Group → продукти: `pro_monthly`, `pro_yearly` (+ `family_*`); Lifetime — Non-Consumable.
3. Ціни по регіонах (price tiers), локалізовані описи, intro/тріал (Introductory Offer — 7 днів free).
4. Сендбокс-тестери для перевірки; підписки рев'ю разом з апом.

**Google — Play Console:**
1. Merchant account + Monetization setup.
2. Monetize → Subscriptions → base plans + offers (monthly/annual, free trial, intro price), ціни по країнах, активувати.

**RevenueCat (зверху):** створюєш продукти в обох сторах → мапиш у RevenueCat → SDK у апі дає один entitlement `pro`. Гейтинг платних фіч у застосунку по цьому entitlement.

## 6. Інтеграції магазинів (ринки)
`PriceSource`-абстракція, провайдер по регіону:
| Регіон | Замовлення | Провайдер |
|---|---|---|
| 🇺🇦 Україна | ✅ | Silpo MCP |
| 🇺🇸 США | ✅ сильно | **Instacart Developer Platform + MCP** (сотні мереж), + Kroger API/MCP |
| 🇪🇺 Європа | 🟡 частково | поки «список покупок»; замовлення — де зʼявляться API (Tesco/Carrefour закриті) |
- Instacart MCP: агент створює shopping-list/shoppable-рецепт, юзер оформлює в Instacart («order my usual groceries…»). Одна інтеграція = багато мереж США.
- EU без ordering-API → фолбек «згенерувати список», без 1-тап замовлення.
